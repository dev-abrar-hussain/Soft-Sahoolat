A quieter feed workflow

Generate once. Serve fast. Stay current.

WooFeeds Pro separates catalog generation from feed delivery. Products are processed in controlled batches, then published as static files that channels can fetch without running a live database query on every request.

01

Scheduled snapshots

Refresh hourly, twice daily or daily with WP-Cron, or use the direct WP-CLI command from a real server cron.

02

Beginner-friendly mapping

Map brand, GTIN and MPN from WooCommerce attributes, product properties or the custom fields already used by your store.

03

Validation in plain language

See exactly how many products are missing titles, identifiers, images, prices or country targeting before you submit a feed.

04

Variation-aware exports

Publish purchasable variations as separate items while preserving their shared product group for channel-side matching.

05

Stable hosted URLs

Give each channel one permanent feed URL. Regeneration safely replaces the snapshot without changing its public address.

06

Fail-safe publishing

Temporary generation errors do not delete the last completed feed, so a transient failure does not erase your catalog.

Licensing designed for real stores

One license. One active domain. Easy migration.

A license binds to the first domain that activates it. Scheduled validation is cached locally, a temporary server outage receives a grace period, and store owners can deactivate before moving staging to production.

Domain locked

A key cannot silently activate on a second domain while it remains attached to the first.

Offline grace

Previously validated stores keep working during temporary licensing-server downtime.

Migration ready

Deactivate from the old domain, then activate the same key on the new store.

Common questions

Before you install.

Does every feed request query WooCommerce?

No. WooFeeds Pro reads products during scheduled or manual generation and writes a completed static file. Public feed requests serve that snapshot.

Are variable products supported?

Yes. When variation export is enabled, each visible purchasable variation becomes a separate feed item with its own price, stock and identifiers.

What if some products have no GTIN?

The validator reports missing identifiers. Google feeds can mark products without known identifiers appropriately; platform eligibility still depends on the product and destination rules.

Can I use a real server cron?

Yes. Run wp woofeeds generate through WP-CLI, or trigger WordPress cron from your server scheduler.

What happens when the license server is offline?

A previously validated license can enter the configured offline grace period. Existing feed files are preserved even when new generation is blocked.
