License guide

Activation and migration.

WooFeeds Pro uses a one-time license model with one active normalized domain per key.

How domain locking works

The first successful activation binds the license to the site's normalized host name. The www. prefix is removed so www.example.com and example.com resolve to the same license domain. Other subdomains remain separate domains.

A key already bound to another domain receives this error:

This license is already active on another domain

Activate a license

  1. In WordPress, open WooCommerce → WooFeeds Pro → License.
  2. Enter the HTTPS license-server API URL and save it.
  3. Paste the key exactly as delivered.
  4. Select Activate License.
  5. Confirm the status shows Active and the expected domain.

Validation and offline grace

The plugin schedules a license check daily and forces a fresh check when a successful result becomes older than 48 hours. A temporary network or server failure can move a previously valid key into the configured grace period.

  • An explicit server rejection does not receive offline grace.
  • A server outage does not delete existing generated feed files.
  • New generation stops after the grace period expires.
  • The next successful validation restores Active status.

Move staging to production

  1. Open the License tab on the old domain.
  2. Select Deactivate.
  3. Migrate the WordPress site.
  4. Open the License tab on the new domain.
  5. Confirm the API URL, then activate the same key.
Deactivate before changing DNS or URLs. If the old installation is no longer accessible, the license owner must clear the activation through the licensing service before the new site can activate.

Development environments

Developers can bypass the license check locally by adding the following to wp-config.php:

define( 'WOOFEEDS_PRO_DEV_MODE', true );

Never ship or enable this constant on a production store.

Information sent to the license service

  • License key
  • Normalized domain
  • WordPress home URL
  • WooFeeds Pro version

Product, order and customer catalog data are not sent to the license service by the WordPress plugin.
