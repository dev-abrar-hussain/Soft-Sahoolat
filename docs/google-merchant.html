Google Merchant Center.

Generate a complete RSS 2.0 XML snapshot and let Merchant Center retrieve it from one stable HTTPS URL.

Before you connect

Complete the general installation, field mapping and validation steps first. Your public product pages and images must use absolute URLs that Google can access.

Recommended product data

  • Stable SKU or WooCommerce product ID
  • Title and factual description
  • Product URL and main image
  • Positive regular price and store currency
  • Current stock availability and condition
  • Brand plus GTIN and/or MPN when assigned
  • Google product category where appropriate
Do not invent identifiers. If a manufacturer assigned a GTIN, submit the correct one. For products that genuinely have no known brand, GTIN or MPN, WooFeeds Pro writes identifier_exists=no.

Configure WooFeeds Pro

  1. Open WooCommerce → WooFeeds Pro → Google Merchant.
  2. Enable the Google feed.
  3. Enter the official Google product category ID or full category path when relevant.
  4. Save, run validation and correct important warnings.
  5. Open Dashboard and select Regenerate Now.

Your URL follows this pattern:

https://example.com/wc-feeds/google-merchant.xml

Add the feed to Merchant Center

  1. In Merchant Center, open Settings → Data sources.
  2. Under product sources, add a product source.
  3. Choose the option to add products from a file or file link.
  4. Paste the direct WooFeeds Pro XML URL.
  5. Select the target country, language and fetch schedule that match your store.
  6. Save the source and run the first fetch.

Google's interface can change over time. The essential requirement is a scheduled file-based product source pointing directly to the XML file—not to an HTML landing page.

After the first fetch

  • Review the Latest update or diagnostics report.
  • Fix product-specific policy or attribute errors in WooCommerce.
  • Regenerate the feed.
  • Trigger another fetch or wait for the next scheduled update.

Common issues

MessageWhat to check
File not foundRegenerate the feed and open the XML URL in a private browser window.
Invalid XMLConfirm no security or optimization plugin is injecting HTML into the feed response.
Price mismatchThe feed, product page, structured data and checkout must show consistent price and currency.
Invalid GTINUse the manufacturer-assigned digits only; WooFeeds Pro also checks length and checksum.
Image unavailableConfirm the original image file exists and is publicly accessible to Googlebot.
