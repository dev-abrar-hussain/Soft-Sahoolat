Install the plugin

  1. Download the current ZIP package.
  2. In WordPress, go to Plugins → Add New Plugin → Upload Plugin.
  3. Select the ZIP, choose Install Now, then Activate.
  4. Open WooCommerce → WooFeeds Pro.
Dependency check: If WooCommerce is not active, WooFeeds Pro displays an admin notice and does not load its product-feed services.

Connect your license

  1. Open the License tab.
  2. Enter the HTTPS license-server base URL supplied with your license.
  3. Save the connection.
  4. Enter your license key and select Activate License.

The first successful activation binds the key to the current normalized domain. Read Licensing and domain migration before changing domains.

Map product fields

Open Field Mapping and select a source for each identifier:

Feed fieldTypical sourceWhy it matters
Brandpa_brand product attributeRequired by ChatGPT and commonly required for manufacturer identifiers.
GTINWooCommerce Global Unique IDIdentifies a standardized trade item. Must have 8, 12, 13 or 14 digits and a valid check digit.
MPN_mpn custom fieldManufacturer-assigned identifier used when GTIN is unavailable.

Enable Export each purchasable variation if your variable products should appear as separate channel items. A variation inherits mapped values from its parent when its own value is empty.

Configure channel details

  • Google: enable the feed and enter a Google product category when appropriate.
  • Meta: enable the feed and optionally add Google and Facebook product categories.
  • ChatGPT: enter the seller name, two-letter store country and comma-separated target countries.

Run catalog validation

Open Validation and select Run Validation. WooFeeds Pro checks the same normalized values used during export and reports:

  • missing titles, descriptions, brands and identifiers;
  • invalid GTIN lengths or checksums;
  • missing or invalid main images and missing local image files;
  • missing positive prices; and
  • missing ChatGPT country targeting.
Validation warnings are actionable, not all-or-nothing. A missing optional field may be acceptable for one platform while blocking another. Use each channel's diagnostics after submission as the final authority.

Generate feeds

From Dashboard, select Regenerate Now. The completed files are stored under wp-content/uploads/wc-feeds/ and exposed at stable URLs:

https://example.com/wc-feeds/google-merchant.xml
https://example.com/wc-feeds/meta-commerce.xml
https://example.com/wc-feeds/chatgpt-products.jsonl.gz

For a real server cron, use:

wp woofeeds generate --path=/path/to/wordpress
