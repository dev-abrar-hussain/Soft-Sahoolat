Meta Commerce Manager.

Keep a Meta catalog updated from a hosted Google-style XML data feed generated directly from WooCommerce.

DocumentationGetting startedGoogle MerchantMeta CommerceChatGPT BusinessLicensingTroubleshooting

What the Meta feed contains

WooFeeds Pro creates an RSS XML catalog with product ID, title, description, availability, condition, price, sale price, product URL, image, brand, GTIN, MPN and category fields. Variations receive a shared item group ID.

Availability is translated to Meta-friendly values such as in stock, out of stock and available for order.

Configure WooFeeds Pro

  1. Open WooCommerce → WooFeeds Pro → Meta Commerce.
  2. Enable the Meta feed.
  3. Enter a Google product category where it improves classification.
  4. Add a Facebook product category when your catalog setup requires it.
  5. Save settings, validate the catalog and regenerate.

Your Meta feed URL follows this pattern:

https://example.com/wc-feeds/meta-commerce.xml

Connect the catalog

  1. Open Commerce Manager and select or create the catalog for your business.
  2. Open the catalog's data sources area.
  3. Choose a data feed and the scheduled or URL-based upload method.
  4. Paste the direct WooFeeds Pro XML URL.
  5. Select a regular update schedule and the correct default currency/country settings.
  6. Start the first upload and review its diagnostics.
Interface note: Meta changes Commerce Manager navigation regularly. Look for Catalog, Data sources, Data feed or Scheduled feed. The feed URL itself remains the same.

Product variations

When variation export is enabled, each purchasable variation has its own item ID, URL, price, availability and mapped identifiers. Meta can group the variations using item_group_id.

Common issues

IssueResolution
Missing required fieldRun WooFeeds validation, edit the affected WooCommerce product and regenerate.
Duplicate retailer IDMake sure every product or variation has a unique SKU, or allow WooFeeds Pro to fall back to the unique product ID.
Currency or price errorConfirm the WooCommerce store currency and product price are valid.
Image cannot be fetchedCheck the media file, HTTPS certificate, hotlink rules and CDN access.
Catalog stays staleVerify Meta's schedule and check the WooFeeds Dashboard for the last successful generation time.

Recommended operating routine

  • Regenerate at least daily for an active catalog.
  • Use hourly refreshes if stock or pricing changes frequently.
  • Keep the stable feed URL—do not create dated filenames.
  • Review Meta diagnostics after major catalog changes.
