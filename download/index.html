Install in minutes

Upload, activate, configure.

  1. In WordPress, open Plugins → Add New → Upload Plugin.
  2. Select the downloaded ZIP and choose Install Now.
  3. Activate WooFeeds Pro.
  4. Open WooCommerce → WooFeeds Pro.
  5. Connect your license server, activate a key and complete field mapping.
